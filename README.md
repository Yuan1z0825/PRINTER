# PRINTER

**PRINTER** is a virtual staining framework for digital pathology, consisting of two main modules:

* **Stain Normalization (PRINTER-N):** restores staining quality and reduces inter-institutional staining variability.
* **Cross-modal Generation (PRINTER-T):** generates virtual histological staining modalities from input pathology images.

---

## 1. Stain Normalization

### 1.1 Data Preparation

Organize the dataset using the following directory structure:

```text
datapath/
├── trainA/
├── trainB/
├── testA/
└── testB/
```

where:

* `trainA/`: training images from domain A
* `trainB/`: training images from domain B
* `testA/`: test images from domain A
* `testB/`: test images from domain B

### 1.2 Model Training

Run the following command to train PRINTER-N:

```bash
python train.py \
    --dataroot ./data_path \
    --dataset unaligned2 \
    --model printern \
    --batch_size 1 \
    --gpu_ids 0 \
    --name result_printern_datapath \
    --epoch 50
```

### 1.3 Model Inference

After training, run the following command for inference:

```bash
python test.py \
    --num_test 9999999 \
    --dataroot ./data_path \
    --dataset unaligned2 \
    --model printern \
    --name result_printern_datapath \
    --results_dir ./results/result_printern_datapath \
    --epoch 50
```

The inference results will be saved to:

```text
./results/result_printern_datapath/
```

## 2. Cross-modal Generation

**PRINTER-T** performs virtual staining between different histological modalities. To generate different target staining modalities, only the corresponding dataset paths need to be changed.

### 2.1 Data Preparation

Organize the dataset using the following directory structure:

```text
datapath/
├── trainA/
├── trainB/
├── testA/
└── testB/
```

where:

* `trainA/`: training images from the input modality
* `trainB/`: training images from the target modality
* `testA/`: test images from the input modality
* `testB/`: test images from the target modality

### 2.2 Model Training

Run the following command to train PRINTER-T:

```bash
python train.py \
    --dataroot ./data_path \
    --dataset aligned3 \
    --model printert \
    --batch_size 1 \
    --gpu_ids 0 \
    --name result_printert_datapath \
    --epoch 200
```

### 2.3 Model Inference

After training, run the following command for inference:

```bash
python test.py \
    --num_test 9999999 \
    --dataroot ./data_path \
    --dataset aligned3 \
    --model printert \
    --name result_printert_datapath \
    --results_dir ./results/result_printert_datapath \
    --epoch 200
```

The inference results will be saved to:

```text
./results/result_printert_datapath/
```

## 3. Multimodal Fusion

**BioX-CPath** is a multimodal computational pathology framework designed to integrate information from multiple histological staining modalities for downstream pathological assessment and clinical outcome prediction.

For the implementation of the multimodal fusion model, please visit the official repository:

## 4. Parameter Description

| Parameter       | Description                            |
| --------------- | -------------------------------------- |
| `--dataroot`    | Root directory of the dataset          |
| `--dataset`     | Dataset type                           |
| `--model`       | Model name                             |
| `--batch_size`  | Batch size                             |
| `--gpu_ids`     | GPU ID                                 |
| `--name`        | Experiment name                        |
| `--epoch`       | Training epoch used for inference      |
| `--num_test`    | Number of test images                  |
| `--results_dir` | Directory for saving inference results |

> **Note:** For cross-modal generation, different target staining modalities can be generated by preparing the corresponding input/target datasets and modifying the dataset path and experiment name accordingly.
